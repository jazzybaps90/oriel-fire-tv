# Oriel for Fire TV

Latest version: **1.1.0 (build 4)**. [Versioned release](https://github.com/jazzybaps90/oriel-fire-tv/releases/tag/v1.1.0).

Official preview APK downloads for Oriel, a personal IPTV playlist player.

## What changed in 1.1.0

- Visible remote focus, clearer channel names and separate country/quality labels.
- On now and Up next guide listings from your provider account or XMLTV guide link.
- Country and language preferences detected during setup and remembered in Settings, with preferred audio selection when available.
- Fixed saved playlists disappearing after a restart.

Verified with 93 automated tests and Android emulator checks for D-pad/Select/Back, guide import, saved preferences, restart restoration and audio selection. Programme listings depend on your provider's guide feed.

## Install

**Downloader code: 2690434** ([short link](https://aftv.news/2690434)). Open Downloader, enter the code, choose Go, then Install. The existing code now downloads version 1.1.0. You can install it over the previous preview. In Oriel, open Settings, scroll to About and check that it says **1.1.0**. The download filename stays the same so the existing code keeps working.

1. Download [Oriel-Firestick-v1.0.apk](https://github.com/jazzybaps90/oriel-fire-tv/releases/download/v1.0.0/Oriel-Firestick-v1.0.apk) using Downloader on your compatible Fire TV.
2. Allow Downloader to install apps when your Fire TV asks, then select Install.
3. Open Oriel and add your own playlist or provider details.

Supports Android API 24 and above (including Fire OS 6, 7 and 8), with 32-bit and 64-bit ARM libraries. Vega OS devices cannot install Android APKs. Fire OS 5 devices are unsupported by this build.

This repository hosts APK releases only. No channels or subscriptions are included. This is a personal preview build; compatibility has not yet been confirmed on a physical Firestick.
